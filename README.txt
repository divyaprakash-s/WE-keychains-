WE KEYCHAINS — WEBSITE STARTER
================================

This is the first front-end version of WE Keychains.
Design: white + emerald green (#047857)
Brand line: Make every memory personal.

PREVIEW
1. Extract the ZIP file.
2. Open index.html in a browser.
3. On Android, you can upload the extracted files to your GitHub repository.

IMPORTANT BEFORE PUBLISHING
- The products, prices and product photos are sample/demo content. Replace them with your real products and images.
- No real payment processing is connected.
- Cart and product filtering work in the browser, but checkout is not yet connected.
- Custom requests and cart order enquiries open WhatsApp with a pre-filled message. They are not stored in a website database.
- WhatsApp contact 9363978844 is connected to the contact link, custom request form and order enquiry button. Verify this number is correct before publishing.
- The admin dashboard, Firebase database, secure admin authentication, image uploads and order storage are the next development stage. Do not publish an insecure client-side admin login.

GITHUB PAGES
1. Create a repository named we-keychains (or another name you prefer).
2. Upload index.html, style.css, script.js and README.txt to the repository root.
3. In GitHub repository Settings > Pages, choose Deploy from a branch.
4. Select the main branch and /(root), then Save.
5. GitHub will show your published website address in the Pages section.
